## 2. Falha encontrada e corrigida — sintaxe de busca

A docstring de `ppubs_search_patents` documenta sintaxe de **prefixo** (`TTL/`, `IN/`,
`AN/`, `CPC/`). O PPUBS usa BRS de **sufixo**. Evidência coletada ao vivo:

| Query | Resultado |
| :--- | :--- |
| `biodegradable AND packaging` | ❌ devolveu 3 patentes de anticorpos anti-idiotípicos — query ignorada, retornou as concessões mais recentes com `success: true` |
| `TTL/biodegradable` | ❌ 0 resultados, sem erro |
| `TTL/"neural network"` | ❌ `INTERNAL_SERVER_ERROR` |
| `("6103599").pn.` | ✅ 1 resultado exato |
| `(biodegradable AND packaging).ti.` | ✅ relevante |
| `(B65D65/46).cpc.` | ✅ relevante |

**Por que isto importa mais que um bug comum.** O caso ruim devolve números de patente
**reais, verificáveis e irrelevantes**. O critério de aceite originalmente planejado
("abrir 3 números no PPUBS e conferir título e data — 3/3 = passa") teria **passado** com
resultados inúteis. Critério corrigido no item 3.

Correção aplicada: `references/busca-ppubs-brs.md` na skill, com a tabela de sufixos, os
operadores (`ADJn`, `SAME`, `$`) e a receita de três ângulos. O vendor não foi tocado —
é read-only e re-clonável.

## 3. Aceite funcional

**Caso:** sistema de filtragem molecular em embalagens biodegradáveis.
**Método:** três ângulos independentes, união dos resultados.

### Critérios — corrigidos

| # | Critério | Resultado |
| :-- | :--- | :--- |
| 1 | ≥5 documentos US com número, título, data e titular | ✅ 14 |
| 2 | Abrir 3 números no PPUBS e conferir título + data — 3/3 | ⬜ **pendente de conferência manual** |
| 3 | **Relevância**: ≥3 dos 5 primeiros de cada ângulo tratam do domínio consultado | ✅ CPC 5/5, termo 5/5, reiv. 3/5 |
| 4 | **Divergência**: os três ângulos não retornam o mesmo conjunto | ✅ só US 12.679.613 aparece em dois ângulos |
| 5 | Nenhum número inexistente | ✅ nenhum erro de recuperação |

O critério 3 é o que a versão anterior não tinha e é o que separa "a ferramenta respondeu"
de "a ferramenta respondeu certo". O ângulo por reivindicação trouxe 2 ruídos
(*Brachytherapy device*, *airtightness of buildings*) — esperado, já que `.clm.` conjuga
três palavras comuns. Ruído em um ângulo é aceitável; a triagem é humana.
